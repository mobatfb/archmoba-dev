# MULTIMANDO FUTUREO — Anfitrión compacto v2.4.2

Ventana inicial de 600 x 600 píxeles, ampliable. Cinco pestañas independientes:
INICIO, TRANSMISIÓN, JUGADORES Y COLA, CONFIGURACIÓN y EVENTOS.

- Fuentes, espacios internos, filas y pestañas compactados.
- Previsualización adaptada al área disponible, conservando proporciones.
- Tabla con desplazamiento vertical y horizontal; botones P1–P8 visibles.
- Diálogos de configuración compactados.

## Instalación
1. Cierra el anfitrión anterior.
2. Extrae todos los archivos del ZIP a una carpeta.
3. Abre el ejecutable FUTUREO VJOY v0.8.4 original y crea los mandos.
4. Ejecuta MULTIMANDO_FUTUREO_Anfitrion_v2_4_2.py.

Esta revisión parte de v2.4.0, no incorpora la modificación HID v0.8.5 /
anfitrión v2.4.1 que está en revisión. No modifica la web, el driver, las
entradas de mandos, los turnos ni los protocolos FULL/DELTA/SMART.
La incidencia del movimiento anormal debe investigarse por separado.
