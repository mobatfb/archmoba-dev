FUTUREO VJOY - PAQUETE EXPERIMENTAL PARA PC SECUNDARIA
=====================================================
Version: LAB v0.5.1; Windows 10/11 x64; 22-11-2026.

OBJETIVO
--------
Probar el driver propio FUTUREO VJOY con 1 hasta 8 mandos virtuales HID.
NO ES UN CONTROLADOR OFICIAL NI DE PRODUCCION. Puede bloquearse, no cargar,
mostrar nombres genericos o causar errores de Windows. No se ha probado
in situ en la computadora del usuario.

PASOS
-----
1. Extraer TODO el ZIP en una carpeta de la PC secundaria. No ejecutar
   directamente los .BAT dentro del ZIP.
2. Tener una copia de seguridad y la clave de recuperacion BitLocker
   si ese equipo tiene cifrado de disco. Windows 10/11 x64 requerido.
3. Ejecutar INSTALAR.bat (doble clic). La version v0.4.1 solicita
   permisos de administrador mediante el aviso UAC, ANTES de abrir el menu.
   Debes aceptar UAC y usar una cuenta con permisos de administrador.
   Si prefieres, clic derecho sobre INSTALAR.bat y Ejecutar como administrador.
4. Elegir 1: PREPARAR MODO PRUEBA. Aceptar el cambio solo si lo deseas.
   El script usa BCDEDIT /SET TESTSIGNING ON. Reiniciar MANUALMENTE.
   Si Windows rechaza el cambio por Secure Boot, el script no lo desactiva.
   Decide si deseas usar una VM o cambiar firmware tras revisar BitLocker.
5. Ejecutar de nuevo INSTALAR.bat. Elegir 2: INSTALAR 1 MANDO.
   El script comprueba SHA-256 del paquete y el certificado, pide permiso
   para confiar en el certificado de prueba y verifica las firmas.
   La version v0.4.2 muestra que almacen rechazó el certificado.
   Si Import-Certificate falla, prueba la herramienta oficial CertUtil sin
   modificar directivas ni permisos de Windows. Si persiste el error,
   usa DIAGNOSTICAR_CERTIFICADO.bat y entrega su resultado. En equipos
   administrados una directiva puede impedir instalar certificados.
   NO desactives protecciones ni cambies permisos del Registro.
   Instala FutJoy.inf y crea ROOT\FUTJOY01 con funciones SetupAPI.
6. Abrir Ejecutar de Windows (Win+R) y escribir: joy.cpl
   Comprobar si aparece el mando y si mueve sus ejes/botones.
7. Si P1 funciona, usar INSTALAR_8_MANDOS.bat o opcion 3 del menu.
8. Abrir DIAGNOSTICAR.bat; si tienes Python 3 tambien comprueba el
   Product String HID real de cada PID, sin alterar dispositivos.
9. ABRIR_GUI.bat abre la interfaz Python opcional (requiere Python 3).
10. Para eliminar los mandos, DESINSTALAR.bat. Al terminar las pruebas,
    VOLVER_MODO_NORMAL.bat desactiva TESTSIGNING (reinicio manual).

SEGURIDAD
---------
- NO desactiva Secure Boot, BitLocker o Integridad de memoria.
- NO altera vJoy ni ViGEmBus. Solo manipula IDs ROOT\FUTJOY01..08.
- Importar un certificado de prueba en LocalMachine/Root permite confiar
  en software firmado con ese certificado. Retiralo al finalizar las pruebas.
- La firma de prueba permite desarrollar en laboratorio, no sustituye la
  firma oficial de Microsoft para distribuir el controlador.
- Si el driver produce BSOD, arranca en modo seguro y desinstala el driver
  desde el Administrador de dispositivos. Revisa setupapi.dev.log.
- Si BCDEdit pide desactivar Secure Boot, no lo cambies automaticamente.
  Con BitLocker activo podrias necesitar la clave de recuperacion.
- Aunque cada PID es diferente, algunos juegos muestran el mismo nombre.
  El diagnostico muestra si la cadena HID Product String es distinta.
- HID/DirectInput no es un gamepad Xbox XInput. Los juegos solo XInput pueden
  no reconocerlo.
- VID 0xF7A0 es un ID de laboratorio, NO un VID licenciado.

RESULTADO DEL PRIMER MANDO (v0.4.3)
---------------------------------
El diagnostico real confirmo ROOT\FUTJOY01\0000 como PnP OK y la interfaz
HID VID:PID F7A0:2101 como DETECTADA. Product String: HID VHF Driver,
nombre generico provisto por Windows VHF. La etiqueta del dispositivo
raiz PnP es FUTUREO VJOY1 - PLAYER 1. Todavia no sabemos si joy.cpl
reconoce el mando ni si se mueven los ejes/botones; hay que probarlos.

Antes de crear P2...P8, ejecuta PROBAR_MANDO_1.bat. El BAT abre joy.cpl.
Selecciona el mando de juego, abre Propiedades y vuelve al BAT para
iniciar una secuencia de eje X y boton 1 (3 ciclos, centrado al terminar).
Requiere Python 3 instalado. No necesita reinstalar drivers ni agregar
certificados. Si no hay respuesta visual, captura el mensaje que muestra
la consola y comparte si P1 aparece o no en joy.cpl.

El diagnostico Python ahora no presenta SyntaxWarning por escapes ni
indica erroneamente que Windows no tiene drivers instalados.

GUI v0.5.0: YA NO DEPENDE DE DEVCON.EXE
-------------------------------------
El GUI usa el mismo instalador PowerShell y SetupAPI/pnputil de Windows.
Si P1 ya funciona, NO es necesario reinstalar el controlador de kernel.

Extrae el ZIP v0.5.0 y abre ABRIR_GUI.bat (Python 3 requerido).
Para agregar P2: selecciona Cantidad=2 y CREAR DISPOSITIVOS.
El instalador salta los puestos que ya existan y pide confirmaciones/UAC.
Se abre una consola interactiva; espera a que termine y confirma con tecla.
QUITAR SELECCIONADO retira SOLO el puesto indicado, sin borrar el driver
ni el certificado que otros puestos siguen necesitando.

Para intentar cambiar el nombre mostrado en joy.cpl: Cantidad=1, pulsa
ETIQUETAR EN WINDOWS, autoriza UAC si hace falta, confirma el alias OEM
y cierra/abre completamente joy.cpl. Los alias se respaldan y pueden
restaurarse mediante RESTAURAR NOMBRES.
IMPORTANTE: la cadena HID Product String interna sigue siendo
'HID VHF Driver', porque VHF gestiona sus propias cadenas HID.
El alias DirectInput es una prueba reversible, no una garantia
de que todos los juegos muestren el mismo nombre.

PRUEBA REAL P1:
El usuario confirmo en joy.cpl dos ejes X/Y, 16 botones y movimiento
del eje X y boton 1 durante la prueba del dispositivo P1.
El driver SYS/CAT sigue siendo el mismo compilado y firmado para LAB.


CORRECCION POSTERIOR AL ZIP v0.5.0: ERROR PNPUTIL 259
---------------------------------------------------
El ZIP v0.5.0 original contiene una validacion de PnPUtil que puede
interrumpir la creacion de P2 cuando P1 ya esta instalado.
La version corregida del instalador esta en el repositorio:
https://raw.githubusercontent.com/mobatfb/archmoba-dev/main/MULTIMANDO/FUTUREO_VJOY/instalador_windows/HERRAMIENTAS/instalador.ps1
Sustituye exclusivamente HERRAMIENTAS/instalador.ps1 dentro de la
carpeta EXTRAIDA del ZIP, con la GUI cerrada. No reinstales P1.
El controlador SYS/CAT firmado, el certificado y los hashes no cambian.
El instalador separa el registro del paquete de la creacion de cada
dispositivo ROOT, y tolera 259 con registro explicativo.
Requiere validacion manual de P2 en joy.cpl.


GUI LAB v0.5.1: IDENTIFICAR P1..P8 SIN CONFUNDIR MANDOS
-----------------------------------------------------
La GUI consulta el HID presente y marca P1..P8 DETECTADO o NO DETECTADO.
Cada P tiene VID:PID distinto (P1=F7A0:2101, P4=F7A0:2104).
Pulsar ACTUALIZAR ESTADO para verificar tras crear o quitar mandos.
Abrir joy.cpl y Propiedades para un mando; seleccionar P en la GUI y pulsar
IDENTIFICAR P SELECCIONADO para ver cual eje X y boton 1 responden.
Para aplicar alias a cuatro mandos: Cantidad=4 > ETIQUETAR EN WINDOWS,
aceptar UAC y confirmacion. Cerrar y abrir joy.cpl (no cambia HID interno).
VER ETIQUETAS consulta el Registro sin modificarlo.
RESTAURAR NOMBRES recupera los valores anteriores del respaldo.
No reinstalar SYS/CAT de prueba ni modificar hashes.
