# Orbit Launcher v0.13 — Puntos verdes manuales

- Indicador verde circular (13 dp) arriba a la derecha de las apps marcadas, como el boceto aprobado.
- Mantén pulsado cualquier icono y elige **Marcar novedad** o **Quitar punto verde**. El menú conserva **Añadir / Subir / Bajar / Quitar**.
- El punto es manual: no afirma detectar automáticamente mensajes ni lee notificaciones.
- Las marcas y el orden se guardan localmente; al retirar una aplicación se elimina su marca.
- Se conservan los círculos y el efecto glass al 55 %, el botón + que aparece solo cuando no hay apps, y el sensor de giro optimizado de v0.12.
- Sin permisos adicionales, sin Internet, sin grabación de pantalla.

Android 8+. APK de pruebas, firma debug.
